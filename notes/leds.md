из тыканья пальцами и написав такой скриптик
```bash
echo === staring ===
LEDS=/sys/class/leds
for ledvar in $(ls "$LEDS"); do
    printf "Maxing out %-20s" "$ledvar"
    echo 255 > "$LEDS/$ledvar/brightness" 2>/dev/null
    sleep 2
    echo 0 > "$LEDS/$ledvar/brightness" 2>/dev/null
    printf "\r"
done
printf "\n"
```

## выясниалсь такая структура:

есть две секции светодиодов. на значке алисы и индикатор заряда. 

их управление находится в `/sys/class/leds`

далее идут папки формата `mango:<ЦВЕТ>:logo<НОМЕР СВЕТОДИОДА>`

mango - внутрененее название устройства

в случае индикаторов заряда:
- они почему то располагаются в цвете `red`? хотя сами белого цвета и есть отдельные папки для белого 
- в названии папки вместо `logo` - `charge`
- отсчитываются с 0 и идут сверху вниз

в каждой папке файл `brightness` - 0-255 яркость
все остальное лучше не трогать :)
